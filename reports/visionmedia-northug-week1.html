Hvorfor dette dokumentet

Pilot-briefen (/r/visionmedia-pilot) viser hvilken klient som er best egnet for første pilot. Dette dokumentet viser hva klientens tech-kontakt faktisk får i hendene uke 1.

Alle kodeblokker under er ferdige utkast — klar til pull-request, ikke skisser. Du kan videresende denne URL-en direkte til klienten som dokumentasjon på hva pilot-uke 1 leverer.

Utgangspunktet (verifisert 2026-05-31)

Northug.com AEO-skår 20/100 (F). Fire blokkeringer holder scoren der.

  • 1.robots.txt blokkerer alt. User-agent: * Disallow: / — ChatGPT, Perplexity, Claude, Gemini hverken indekserer eller siterer.
  • 2.HTML er en tom Vue-shell. 990 bytes, kun <div id="app"></div> for AI-crawlere som ikke kjører JavaScript (det er alle kommersielle AI-crawlere i 2026).
  • 3.Tittel og meta beskriver ikke produkt. <title>Dynamic Brands</title>, meta description="Dynamic Brands" — navn på e-handelsplattformen, intet om Northug-merket.
  • 4.Kanonisk URL peker bort. <link rel="canonical" href="https://dynamicbrands.no/"> — alt rang-signal flyter til et eksternt domene, ikke Northug.
DAG 1 ~30 min

Åpne robots.txt for AI-crawlere

Beholder eksisterende avvisning av aggressive scrapere, men whitelister de syv crawlerne som mater ChatGPT, Perplexity, Claude og Gemini.

Før (northug.com/robots.txt)
User-agent: *
Disallow: /
Etter
# AI-svartjenester — eksplisitt tillatt
User-agent: OAI-SearchBot
Allow: /

User-agent: ChatGPT-User
Allow: /

User-agent: GPTBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: ClaudeBot
Allow: /

User-agent: Google-Extended
Allow: /

User-agent: CCBot
Allow: /

# Default — fortsatt restriktiv mot bulk-scrapere
User-agent: *
Disallow: /admin/
Disallow: /checkout/
Allow: /

Sitemap: https://northug.com/sitemap.xml

Effekt: AI-crawlere får lov å hente sidene. Uten dette steget gir ingen av de neste seks tiltakene synlighet i AI-svar.

DAG 1–2 ~2 t

Ny /llms.txt — agent-instruks for Northug

Strukturert oppsummering AI-agenter leser når de bygger svar om merket. Følger llmstxt.org spec og samme mønster som Tufte's allerede har.

## Fakta-anker for AI-svar

Effekt: når en bruker spør «Hvor kjøper jeg norske langrennsklær?», ser AI-agenten en strukturert fakta-pakke å sitere fra — ikke en tom Vue-shell.

DAG 2–3 ~3 t

JSON-LD Organization + Brand schema

Strukturert markup injisert i <head> på forsiden. Validert mot schema.org validator og Googles Rich Results Test før push.

<script type="application/ld+json">
{

  "@graph": [

      "@id": "https://northug.com/#organization",

      "url": "https://northug.com/",
      "logo": "https://northug.com/logo.png",

      "taxID": "NO997701933",

Effekt: Petter er nå en entitet AI-modeller kan resonnere over, ikke et ord på en side. Spørsmål om «Petter Northugs merke» får eksplisitt grunnlag.

DAG 3–4 ~4 t

Server-side fallback for forsiden

SSR-snapshot eller <noscript>-blokk så crawlere ser substans. Sannsynlig minimal-versjon hvis klientens Vue/Laravel-stack ikke har SSR satt opp:

<noscript>
  <header>
    <h1>Northug — norske skiklær og lifestyle</h1>
    <p>Skiklær- og lifestyle-merke fra langrennslegenden Petter Northug. Eies av Northug AS i Mosvik (Inderøy).</p>
  </header>
  <nav>
    <a href="/herre">Herre</a>
    <a href="/dame">Dame</a>
    <a href="/junior">Junior</a>
    <a href="/barn">Barn</a>
    <a href="/om-oss">Om merket</a>
    <a href="/baerekraftig-forretningspraksis">Bærekraft</a>
  </nav>
  <section>
    <h2>Designfilosofi</h2>
    <p>[2–3 setninger fra klienten om kvalitetsstandard, materialvalg, og hva som skiller merket — leveres av kunde uke 1.]</p>
  </section>
</noscript>

Effekt: AI-crawlere som ikke kjører JS (alle de kommersielle) ser navigasjonsstruktur, hovedbudskap og fakta. Dette er den enkleste fiksen — full SSR kommer i uke 2 hvis stack-en støtter det.

DAG 4–5 ~1 t

Riktig <title>, meta og canonical

Forsidens <head> kommuniserer Northug, ikke morselskap. Canonical peker til seg selv så rang-signal stopper i Northug-domenet.

Før
<title>Dynamic Brands</title>
<meta name="description"
      content="Dynamic Brands">
<link rel="canonical"
      href="https://dynamicbrands.no/">
Etter
<title>Northug — norske skiklær
  fra Petter Northug</title>
<meta name="description"
      content="Norsk skiklær- og
  lifestyle-merke fra Petter
  Northug. Eies av Northug AS
  i Mosvik (Inderøy).">
<link rel="canonical"
      href="https://northug.com/">

Effekt: SERP-snippet og AI-utdrag siterer Northug med navn, opphav og kontekst — ikke morselskapets navn.

Score-økningen kommer fra fem komponenter som måles direkte av AEO-modellen: crawlability (robots.txt + llms.txt), strukturert markup (Organization + Brand + Person + WebSite), entitet-grunnlag (Petter Northug som @id), første-substans-treff (noscript-fallback), og kanonisk konsistens. Resterende vei til 75/B (uke 2–4): produkt-schemas, FAQ-blokk, alt-tekst, sitemap, AggregateRating hvis Trustpilot er tilgjengelig — alt detaljert i proposal-en.
